# ISO Channel v0.99 — файлы для производства

Изолированная выходная плата контроллера HiPIMS. Подаёт сигнал пуска на осциллографы, датчики и подобные
нагрузки. Сделано в KiCad 10.0.8 из `Channel.kicad_pcb`.

Файлы для производства лежат в `gerber/`, те же файлы — в архиве `gerber-iso-channel.zip`.

## Плата

| Параметр | Значение |
|---|---|
| Слои | 2 |
| Размер | 55.05 × 59.48 мм, прямоугольник |
| Толщина | 1.6 мм, FR4 |
| Медь | 35 мкм (1 oz), обе стороны — стек слоёв в проекте не задан |
| Мин. дорожка / зазор | 0.2 / 0.2 мм |
| Мин. отверстие | 0.3 мм (переходные) |
| Переходные (площадка / сверло) | 19 × 0.6 / 0.3, 1 × 0.8 / 0.4 мм |
| Металлизированные | выводы 0.7–1.0 мм; 1 × 3.5 мм (крепёж H4) |
| Неметаллизированные | 3 × 3.5 мм (крепёж H1–H3) — отдельный файл |
| Пазы / овальные отверстия | нет |
| Компоненты | только сверху |
| Контроль импеданса | не нужен |
| Покрытие, цвета | в проекте не заданы — выбрать при заказе |

## Файлы

| Файл | Что внутри |
|---|---|
| `Channel-F_Cu.gtl` | Медь, верх |
| `Channel-B_Cu.gbl` | Медь, низ |
| `Channel-F_Mask.gts` | Маска, верх |
| `Channel-B_Mask.gbs` | Маска, низ |
| `Channel-F_Silkscreen.gto` | Шелкография, верх |
| `Channel-B_Silkscreen.gbo` | Шелкография, низ (пустая) |
| `Channel-F_Paste.gtp` | Паста, верх — только для трафарета |
| `Channel-B_Paste.gbp` | Паста, низ (пустая) |
| `Channel-Edge_Cuts.gm1` | Контур платы |
| `Channel-PTH.drl` | Металлизированные отверстия, Excellon, мм |
| `Channel-NPTH.drl` | Неметаллизированные отверстия, Excellon, мм |
| `Channel-job.gbrjob` | Job-файл Gerber |
| `Channel-PTH-drl_map.gbr`, `Channel-NPTH-drl_map.gbr` | Карты сверловки — для справки, фабрике не нужны |

Gerber RS-274X (с атрибутами X2), миллиметры, формат 4.6. Начало координат у всех слоёв общее.
